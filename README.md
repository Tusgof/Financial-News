# Financial News

เว็บไซต์ GitHub Pages สำหรับอ่านสรุปข่าวการเงิน/เศรษฐกิจ/การเมือง รายวัน ที่ถูกสร้างอัตโนมัติโดย Claude routine ทุกเช้า — ออกแบบสไตล์ Apple (โทนหรูมินิมอล, ฟอนต์อ่านง่าย, frosted glass, รองรับ Dark Mode)

🔗 Repo: https://github.com/Tusgof/Financial-News

---

## โครงสร้างโปรเจกต์

```
Financial-News/
├── index.html              # หน้าเว็บหลัก (app shell)
├── .nojekyll               # ปิด Jekyll ของ GitHub Pages (จำเป็นสำหรับ assets/)
├── assets/
│   ├── css/style.css       # ดีไซน์สไตล์ Apple + Dark Mode
│   └── js/app.js           # โหลด manifest + แปลง Markdown เป็นการ์ดข่าว
└── news/
    ├── manifest.json       # รายการวันที่ที่มีข่าว (ใหม่สุดอยู่บนสุด)
    └── YYYY-MM-DD/
        ├── business.md     # หมวด ธุรกิจ / การเงิน / ตลาด
        ├── economy.md      # หมวด เศรษฐกิจ / นโยบาย
        └── politics.md     # หมวด การเมือง / ภูมิรัฐศาสตร์ / สงคราม
```

---

## วิธีทำงานของเว็บ

1. `app.js` อ่าน `news/manifest.json` เพื่อรู้ว่ามีข่าวของวันไหนบ้าง
2. เลือกวันที่ล่าสุดอัตโนมัติ แล้วดึงไฟล์ `.md` ทั้ง 3 หมวดของวันนั้น
3. แปลง Markdown เป็น HTML ด้วย [marked.js](https://marked.js.org/) ฝั่ง client
4. ตกแต่งเพิ่มเติม: ป้าย "ความเชื่อมั่น" (สูง/กลาง/ต่ำ) และชิปลิงก์ "ที่มา"
5. ผู้ใช้สลับหมวด/วันที่ได้ทันที (มี cache ในหน่วยความจำ)

> ไม่มีขั้นตอน build — เป็น static site ล้วน เปิดผ่าน GitHub Pages ได้เลย

## การเชื่อมต่อกับ Claude routine (ทุกเช้า)

ทุกเช้า routine จะรัน prompt 3 ตัว (Business / Economy / Politics) ที่ใช้ **core prompt ร่วมกัน** แล้วบันทึกผลลัพธ์ดังนี้:

### 1) สร้างโฟลเดอร์วันที่
```
news/2026-05-30/
```
ใช้รูปแบบ `YYYY-MM-DD` (เวลาไทย)

### 2) บันทึกผล Markdown ลง 3 ไฟล์
| หมวด | ไฟล์ | บรรทัดหัวเรื่อง |
|------|------|----------------|
| ธุรกิจ / การเงิน / ตลาด | `business.md` | `# 💸💼 สรุปสัญญาณข่าว: ธุรกิจ / การเงิน / ตลาด วันที่: ...` |
| เศรษฐกิจ / นโยบาย | `economy.md` | `# 🏦📈 สรุปสัญญาณข่าว: เศรษฐกิจ / นโยบาย วันที่: ...` |
| การเมือง / ภูมิรัฐศาสตร์ / สงคราม | `politics.md` | `# สรุปสัญญาณข่าว: การเมือง / ภูมิรัฐศาสตร์ / สงคราม วันที่: ...` |

### 3) เพิ่มวันที่ใน `manifest.json` (ใหม่สุดอยู่บนสุด)
```json
{
  "dates": [
    "2026-05-30",
    "2026-05-29"
  ]
}
```
> รองรับทั้งรูปแบบ `{ "dates": [...] }` และอาเรย์เปล่า `[...]` — เว็บจะ sort ใหม่สุดก่อนให้เอง

### 4) commit & push
```bash
git add news/
git commit -m "news: 2026-05-30"
git push
```
GitHub Pages จะอัปเดตหน้าเว็บอัตโนมัติภายในไม่กี่นาที

## รูปแบบ Markdown ของแต่ละหมวด (สำคัญ)

แต่ละไฟล์ **ต้องมี 2 ส่วนเสมอ** คือ Top 3 ระดับโลก และ Top 3 ในไทย:

```markdown
# 💸💼 สรุปสัญญาณข่าว: ธุรกิจ / การเงิน / ตลาด วันที่: 30 พฤษภาคม 2026

## 🌍 3 อันดับข่าวที่สำคัญและมาแรงที่สุดระดับโลก

### 1) [English Headline]

**พาดหัวไทย:** [พาดหัวภาษาไทย]

> **บทวิเคราะห์:** [วิเคราะห์เป็นภาษาไทย]
> **ทำไมคนถึงสนใจข่าวนี้:** [เหตุผล]
> **ความเชื่อมั่น:** สูง   <!-- สูง / กลาง / ต่ำ -->
> **ที่มา:** [ชื่อแหล่งข่าว](https://...)

### 2) ...
### 3) ...

## 🇹🇭 3 อันดับข่าวที่สำคัญและมาแรงที่สุดในประเทศไทย

### 1) ...
### 2) ...
### 3) ...
```

กฎที่เว็บใช้ตีความ:
- `##` = หัวข้อภูมิภาค (🌍 โลก / 🇹🇭 ไทย)
- `### N)` = พาดหัวภาษาอังกฤษของข่าว
- `**พาดหัวไทย:**` = พาดหัวภาษาไทย
- `> ...` (blockquote) = การ์ดเนื้อหาวิเคราะห์
- บรรทัด `**ความเชื่อมั่น:** สูง/กลาง/ต่ำ` → ถูกแปลงเป็นป้ายสี
- บรรทัด `**ที่มา:** [..](url)` → ถูกแปลงเป็นชิปลิงก์ (เปิดแท็บใหม่)

## เปิด GitHub Pages

1. ไปที่ repo → **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` / โฟลเดอร์ `/ (root)`
4. Save — เว็บจะอยู่ที่ `https://tusgof.github.io/Financial-News/`

---

## ทดสอบบนเครื่อง

เปิดเซิร์ฟเวอร์ static ในโฟลเดอร์โปรเจกต์ (จำเป็นเพราะใช้ `fetch` โหลดไฟล์ `.md`):

```bash
# Python
python -m http.server 8080

# หรือ Node
npx serve .
```
แล้วเปิด http://localhost:8080

> เปิดไฟล์ `index.html` ตรง ๆ ผ่าน `file://` จะไม่ทำงาน เพราะเบราว์เซอร์บล็อก `fetch` ไฟล์ในเครื่อง
